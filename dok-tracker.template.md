# DOK Tracker

This is your personal Depth of Knowledge tracker. Copy this file, fill in your skills, and point your agent config at it so Learning Mode can calibrate automatically.

## How to Use

1. List the skills relevant to your growth platform
2. Assign each skill to a Tier (1-4) based on the model below
3. Rate your current DOK level (1-4) for each skill
4. Update as you progress - the agent will also suggest updates when it notices graduation signals
5. Add dated entries to the Progression Log when DOK levels change

## Tier Reference

| Tier | Name | You can... |
|------|------|------------|
| 1 | Orientation | Read it, navigate it, understand explanations |
| 2 | Judgment | Build it, but not yet confident in tradeoff evaluation |
| 3 | Execution | Make good decisions, building fluency and speed |
| 4 | Multiplication | Teach it, see deep patterns, evaluate novel situations |

## DOK Level Reference

| DOK | Label | Meaning |
|-----|-------|---------|
| 1 | Recall | Can recognize and name it |
| 2 | Skill/Concept | Can apply in familiar contexts |
| 3 | Strategic Thinking | Can plan with it, evaluate tradeoffs, adapt to new situations |
| 4 | Extended Thinking | Can synthesize across domains, teach, create new patterns |
